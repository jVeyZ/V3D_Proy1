OPENCV DESDE PYTHON:
INTRODUCCIÓN A LA CALIBRACIÓN DE CAMARAS
INTRODUCCIÓN
OpenCV utiliza el método de calibración de Zhang que utiliza al menos tres imágenes capturadas desde
diferentes puntos de vista de un patrón planar. Los patrones planares tienen la ventaja de que pueden
imprimirse con la precisión de una impresora. En los proyectos de esta asignatura, se deberán calibrar
las cámaras utilizando este método para obtener modelos precisos de las mismas. Los modelos
calibrados de las cámaras servirán para proyectar los objetos virtuales sobre las imágenes capturadas y
generar realidad aumentada de manera efectiva, así como también para localizar los objetos reales en el
entorno, lo que permitirá una interacción más precisa y realista entre el mundo virtual y el mundo real.
Esto abre un abanico de posibilidades para aplicaciones innovadoras en campos como la robótica, la
medicina, la arquitectura, el entretenimiento y muchos más, donde la realidad aumentada y la visión 3D
desempeñan un papel fundamental.
OBJETIVOS
El objetivo principal de esta sesión de prácticas es aprender a calibrar una cámara y utilizar el modelo
calibrado para proyectar al menos un punto virtual sobre las imágenes capturadas por la cámara
utilizando OpenCV desde Python.

Analizar la siguiente función de detección de esquinas en un patrón tipo tablero de ajedrez implementada en la
demo “52_Camera_Calibration_demo.py”:
def getCalibrationPoints(fname):
# Defining the dimensions of checkerboard
patternSize = (6,9)
# Defining the world coordinates for 3D points
objp = np.zeros((1, patternSize[0] * patternSize[1], 3), np.float32)
objp[0,:,:2] = np.mgrid[0:patternSize[0], 0:patternSize[1]].T.reshape(-1, 2)
# Find the chess board corners
img = cv2.imread(fname)
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
imgSize = gray.shape[::-1]
# If desired number of corners are found in the image then ret = true
ret, corners = cv2.findChessboardCorners(gray, patternSize, None)
if ret == True:
# Draw and display the corners
img = cv2.drawChessboardCorners(img, patternSize, corners, ret)
cv2.imshow('img', img)
cv2.waitKey(0)
cv2.destroyAllWindows()
return ret, corners, objp, imgSize
